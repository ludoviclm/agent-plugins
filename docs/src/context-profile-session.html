Switch profiles in plain language.

One sentence in the session. After a reload, it loads only what the work needs.

›switch to the web profile

Switched this folder to the web profile.

It includes basic too. The change is written to .claude\settings.local.json, at the root of my-site.

  • Plugins on: frontend-design and modern-web-guidance.
  • Plugins off: canva, databricks, fabric-skills, figma, miro and powerbi-authoring.
  • Tools denied: Artifact.
  • Unlisted plugins untouched: a plugin named in no profile stays as your user settings leave it.

The plugins and denied tools apply when the session restarts: reload the window, or run claude --continue, to keep this conversation. After the restart, /context shows the result.
